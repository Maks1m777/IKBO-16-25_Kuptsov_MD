# VFS Emulator

Эмулятор командной строки UNIX-подобной ОС с виртуальной файловой системой (VFS).

## Запуск

```bash
python3 vfs_emulator.py [-v PATH] [-s PATH]
```

### Параметры командной строки (Этап 2)

| Флаг          | Длинная форма  | Значение                                  |
|---------------|----------------|-------------------------------------------|
| `-v PATH`     | `--vfs PATH`   | Путь к физическому расположению VFS.       |
| `-s PATH`     | `--script PATH`| Путь к стартовому скрипту команд эмулятора.|

Оба параметра необязательны. При запуске в **stderr** печатается
отладочная сводка всех заданных параметров и выбранный режим:

```
[config] vfs_path    = /data/vfs.img
[config] script_path = vfs_scripts/basic.txt
[config] mode        = script
```

> Примечание: на Этапе 2 параметр `--vfs` принимается и логируется,
> но реальная загрузка VFS выполняется начиная с Этапа 3.

## Режимы работы

- **Интерактивный REPL** (скрипт не задан): обычный диалог, приглашение `VFS$ `.
- **Скриптовый режим** (задан `--script`): команды из файла выполняются
  последовательно; на экран печатается и «ввод» (`VFS$ <строка>`), и «вывод» —
  имитация диалога с пользователем. Пустые и ошибочные строки **пропускаются**
  (выполнение продолжается). Команда `exit` внутри скрипта останавливает
  выполнение. Если файл скрипта не найден — ошибка в stderr и код выхода `1`.

## Поддерживаемые команды (Этап 1)

| Команда         | Описание                                          |
|-----------------|---------------------------------------------------|
| `ls [args...]`  | Заглушка: выводит имя команды и аргументы.         |
| `cd [args...]`  | Заглушка: выводит имя команды и аргументы.         |
| `exit`          | Завершает работу эмулятора.                        |

## Примеры использования (интерактив)

```
VFS$ ls
ls: called with args []

VFS$ ls -la /home
ls: called with args ['-la', '/home']

VFS$ cd /tmp
cd: called with args ['/tmp']

VFS$ unknown_cmd
Error: unknown command 'unknown_cmd'. Type 'exit' to quit.

VFS$ exit
exit: Goodbye!
```

## Примеры с параметрами

```bash
# Скриптовый режим:
python3 vfs_emulator.py --script vfs_scripts/basic.txt

# Оба параметра (короткие флаги):
python3 vfs_emulator.py -v /data/vfs.img -s vfs_scripts/with_errors.txt
```

## Обработка ошибок и сигналов

- **Неизвестная команда** — сообщение в stderr; в интерактиве продолжает
  работу, в скриптовом режиме пропускает строку и идёт дальше.
- **Пустой ввод / пустая строка в скрипте** — игнорируется.
- **Ctrl+C (интерактив)** — прерывает текущую строку, возврат к приглашению.
- **Ctrl+D / EOF (интерактив)** — корректное завершение работы.
- **Ctrl+C (скриптовый режим)** — прерывает выполнение скрипта, код выхода `130`.
- **Отсутствующий файл `--script`** — ошибка в stderr, код выхода `1`.

## Структура репозитория

```
vfs-emulator/
├── vfs_emulator.py        # Эмулятор (REPL + конфигурация + скриптовый режим)
├── README.md
├── .gitignore
├── vfs_scripts/           # Стартовые скрипты эмулятора (списки команд VFS)
│   ├── basic.txt
│   ├── with_errors.txt
│   └── exit_mid.txt
├── os_scripts/            # Bash-скрипты реальной ОС: вызовы эмулятора
│   ├── test_no_args.sh    #   с разными комбинациями параметров
│   ├── test_vfs_only.sh
│   ├── test_script_only.sh
│   ├── test_both.sh
│   ├── test_short_flags.sh
│   └── test_bad_script.sh
└── tests/
    └── test_stage1.sh     # Демонстрация интерактивного режима (Этап 1)
```

## Как прогнать тесты параметров (Этап 2)

```bash
bash os_scripts/test_no_args.sh
bash os_scripts/test_vfs_only.sh
bash os_scripts/test_script_only.sh
bash os_scripts/test_both.sh
bash os_scripts/test_short_flags.sh
bash os_scripts/test_bad_script.sh
```

Каждый скрипт печатает заголовок теста, отладочную сводку параметров (stderr)
и результат работы эмулятора, а также код выхода.
