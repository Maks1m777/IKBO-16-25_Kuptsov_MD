# VFS Emulator

Эмулятор командной строки UNIX-подобной ОС с виртуальной файловой системой (VFS).

## Этап 1: REPL

Минимальный прототип с поддержкой интерактивного режима.

### Запуск

```bash
python3 vfs_emulator.py
```

### Поддерживаемые команды

| Команда | Описание |
|---------|----------|
| `ls [args...]` | Заглушка: выводит имя команды и аргументы |
| `cd [args...]` | Заглушка: выводит имя команды и аргументы |
| `exit` | Завершает работу эмулятора |

### Примеры использования

```
VFS$ ls
ls: called with args []

VFS$ ls -la /home
ls: called with args ['-la', '/home']

VFS$ cd /tmp
cd: called with args ['/tmp']

VFS$ cd
cd: called with args []

VFS$ unknown_cmd
Error: unknown command 'unknown_cmd'. Type 'exit' to quit.

VFS$ exit
exit: Goodbye!
```

### Обработка ошибок

- **Неизвестная команда** — выводится сообщение об ошибке в stderr, эмулятор продолжает работу.
- **Пустой ввод** — строка игнорируется, выводится новое приглашение.
- **Ctrl+C** — прерывание текущей строки, возврат к приглашению.
- **Ctrl+D (EOF)** — корректное завершение работы.
